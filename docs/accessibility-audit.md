## Keyboard-only procedure

1. Reload the website.
2. Do not use the mouse.
3. Use `Tab` and `Shift + Tab` to move through controls.
4. Use `Enter` and `Space` to activate appropriate controls.
5. Check that focus is visible.
6. Check that dialogs and menus can be opened and closed using the keyboard.
7. Record any keyboard trap or unreachable control actually observed.
